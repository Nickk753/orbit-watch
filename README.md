# Orbit Watch

Collision-risk analytics for a satellite operator. **Which of our satellites need an avoidance maneuver this month?**

IE NYC Data Visualization, Session 02 course project.

## Data honesty
- **Real:** satellite orbits from [CelesTrak](https://celestrak.org) GP data (snapshot 2026-11-10): 80 Iridium NEXT satellites and 3,687 tracked objects crossing 600 to 900 km.
- **Synthetic:** close approaches (`fact_conjunction`) and maneuvers (`fact_maneuver`), generated by `pipeline/generate.py` with fixed seed `20261110`. Event rates are proportional to the real object population around each satellite. Every synthetic row has `is_synthetic = true`.

## Layout
| Path | What |
| --- | --- |
| `data/raw/` | CelesTrak snapshot (unchanged source) |
| `data/model/` | Generated star-schema tables (CSV) |
| `pipeline/generate.py` | Seeded generator: raw orbits to model tables |
| `pipeline/checks.py` | Data checks: keys, nulls, orphans, ranges, writes `docs/data-checks.md` |
| `pipeline/load_supabase.py` | Loads the CSVs into Supabase |
| `supabase/migrations/` | Schema, keys, row-level security, KPI views |
| `docs/` | Data dictionary, semantic model, KPI contract, validation |

## Rebuild
```bash
python3 pipeline/generate.py && python3 pipeline/checks.py
```
